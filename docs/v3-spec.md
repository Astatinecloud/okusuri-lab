## 1. 研究項目（内部キー → 表示名）
| キー | 表示名 | モデル上の意味 |
|---|---|---|
| `pot` | 新薬の殺菌力 | EC50（params.json `ec50S`）。耐性菌の EC50 = EC50 × F（F = `resistFoldMutant` = 8、レベルで変わらない） |
| `bar` | 耐性の生じにくさ | (a) 耐性菌の出現頻度 f = `freq[L]`（治療開始時に体内にいる耐性菌 = S0 × f）、(b) 突然変異率 μ = f × c（変異と淘汰のつり合いから導出）、(c) 耐性の増殖コスト c = `cost[L]`（耐性菌の増殖速度 gR = gS(1−c)、地域での感染力 β(1−c)）。**耐性菌への殺菌力（F・Emax）は変えない** |
| `dur` | 薬の効果が続く時間 | 半減期 `halfLife[L]` |
| `gentle` | 安全性 | 副作用係数 `seGentle[L]` |

- 副作用指数: `se = seBase × (1 + sePot[pot] + seBarrier[bar] + seDur[dur]) × seGentle[gentle]`（seBarrier は v2 の seMech と同じ値）。
- 研究コイン: 予算 9 枚、1段階 1 枚、全項目レベル1開始、使い切らなくてよい（既存どおり）。
- URL の4桁 `#r=pbdg` の2桁目は `bar` を表す（v2 URL を開いた場合も新しい意味で解釈してよい）。

## 2. 短期モデル（1人の患者の治療、時間単位）
既存の4状態 ODE（S, Sq, R, Rq；ロジスティック、Hill、半減期、飽和型免疫、一時的耐性状態）を再利用し、以下だけ変える:
- 投与は 0, 12, …, < `Ttreat`(72) h のみ。その後 `Tpost`(72) h は薬なし（免疫のみ）で積分を続ける（合計 144 h、dt = 0.05、RK4、各ステップ後 max(0,·)）。
- 耐性菌: EC50 × F、増殖 gR = gS(1−c)。
- 2種類の感染を計算する:
  - **新薬が効く菌による感染**: 初期 S=S0(1−tolFrac0), Sq=S0·tolFrac0, R=Rq=0。
  - **耐性菌による感染**: 初期 R=S0(1−tolFrac0), Rq=S0·tolFrac0, S=Sq=0。
- 治癒判定: Ttreat(72 h) 時点の活動状態の菌（S+R）< cureThreshold（既存と同じ）。
- **治療中の耐性成立確率**（新薬が効く菌による感染のみ）: model3.py の within_host と同一。
  - 各ステップ i（左端点）で bS·S = gS·crowd·S、b = gR·crowd、d = kR(t) + m·Ki/(Ki+N) を記録。
  - 後ろ向き漸化式 `G = 1 + d·dt + exp(−(b−d)·dt)·(G − 1)`（G(H)=1）。1/G(t) は時刻 t に生まれた耐性菌系統が H まで生き残る確率（Kendall 型の非斉次出生死亡過程）。
  - E = Σ μ·bS·S·dt / G(t_i) + S0·f / G(0)、 pEmerge = 1 − exp(−E)。
- 患者 100 人: 免疫 m_i と副作用耐性 seTol_i は既存の決定論的配置（正規分位点、`patients()` と同じ。log10R0 は使わない）。

## 3. 長期モデル（地域、日単位、1年=365日）
model3.py の `community` と同一（確率的 tau-leaping, dt = 1 日）。
- 状態: 新薬が効く菌の感染者 Y_S、耐性菌の感染者 Y_R（整数）。X = N − Y_S − Y_R。
- 治療成績（短期モデルの患者表から）: eS = mean[(cureS ∧ okSE)·(1 − pEmerge)]、eR = mean[cureR ∧ okSE]、qE = mean[pEmerge]。
- 1日ごと: newS ~ Poisson((β X Y_S/N + import)dt), newR ~ Poisson(β(1−c) X Y_R/N · dt), treatS ~ Bin(Y_S, 1−e^{−τdt}), emerg ~ Bin(treatS, qE), curedS ~ Bin(treatS − emerg, eS/(1−qE)), natS ~ Bin(Y_S − treatS, 1−e^{−γdt})、R も同様（treatR, curedR ~ Bin(treatR, eR), natR）。更新後 max(0,·)。
- 乱数: mulberry32 と Poisson/二項の近似（λ<30 は積の方法、それ以上は Box–Muller 正規近似；n<50 の二項は逐次、それ以外は平均<30 で Poisson、他は正規近似）を **model3.py の Rng と完全に同じ手順** で実装する（golden の rngSeed7 で確認）。
- 月集計: 日 [⌊m·365/12⌋, ⌊(m+1)·365/12⌋) の Y_S, Y_R の平均と耐性菌割合 Y_R/(Y_S+Y_R)、その月の耐性成立件数。
- 100 人の患者: 患者 k は ⌊k·12/100⌋ 月目に治療（各月 8〜9 人）。別系列の乱数 `Rng(seed ^ 0x9E3779B9)` で、確率＝その月の耐性菌割合で耐性菌感染かを決め、新薬が効く菌の感染なら pEmerge で治療中の耐性成立を決める。回復 = (耐性菌感染: cureR ∧ okSE)／(新薬が効く菌: cureS ∧ okSE ∧ ¬成立)。患者の種類 'S','E','R' は golden の `kinds` と一致させる。
- シード: 「シミュレーション開始」時に `crypto.getRandomValues` で 32bit を生成。共有URLに `&s=<seed>` を付け、同じ URL なら同じ結果。`s` がない旧URLは設計から決まる固定シード（例: 1000 + 4桁の数値）。
