# 早稲田祭 運用説明書（スタッフ向け）

## 準備
- 公開URLをブラウザで開くだけ（インストール不要・サーバー不要の静的サイト）。会場の Wi‑Fi が不安定な場合は、事前に一度開いておけば同じタブで遊び続けられる（計算はすべて端末内）。
- 推奨: タブレット横置き / PC。スマホ縦でも遊べる。音は出ない。
- 案内用に公開URLのQRコードを印刷して掲示する（タイトル画面のURL）。

## 1回の流れ（約3〜5分）
1. タイトル →「はじめる」
2. コイン9枚で4つの性能を決める →「薬を完成させる！」→ 薬の名前
3. 体の中のアニメ（約15秒、「けっかを見る」でスキップ可）
4. 結果（回復人数・ランク・コメント）
5. 「けっかを保存する」→ 画像保存 or QRコードをおうちの人のスマホで読み取り →「もう一度つくる」

## 声かけ例
- 1回目のあと:「つよいばい菌はへったかな？ 新しいしくみをためしてみよう」
- 薬の強さを上げても耐性菌が減らない子に:「薬をつよくするだけじゃなくて、しくみを変えるのが大事なんだよ」
- 菌が残っていて不安そうな子に:「少しのこっていても、体の守る力（めんえき）がやっつけてくれるから、元気になった人がたくさんいるね」

## 誤解をさけるための注意（スタッフが言わないこと）
- ×「薬をたくさん飲めば効く」→ ゲームでも投与量は常に同じ。強さは「薬そのものの力」。
- ×「耐性菌は絶対に治らない／根絶できない」→ 3日間の観察で少し残るだけ。
- ×「回復人数は本当の薬の成績」→ ゲーム用の仮の数字。

## トラブル対応
- 画面が固まった: ブラウザを更新（結果画面のURLなら結果が再表示される）。
- 画像が保存できない（iPhone 等）: 表示された画像を長押し →「写真に追加」。またはQRコードで結果URLを持ち帰る。
- 個人情報は一切集めていない。名前入力欄には本名を入れないよう声かけ。

## 設定の変更（開発者向け）
- 予算・レベルのコスト: `src/config/params.json` の `budget`, `levelCost`
- モデルパラメータ: `src/config/params.json`（変更後は `model-ref/sweep.py` でバランス確認し、`model-ref/golden.py` で golden を再生成）
- 文言・ランク基準: `src/config/game.ts`
- 再デプロイ: `npm run build` →  `dist/` をホスティングへ（README 参照）
