# v3 数理モデル仕様書：新薬の使用開始から1年間の薬剤耐性菌の出現・増加

参照実装: `model-ref/model3.py`（Python, numpy）。ゲーム実装: `src/model/index.ts`（golden3 で Python と一致を確認）。パラメータ: `model-ref/params.json`（短期モデル、v1 から不変）＋ `model-ref/params3.json`（v3 追加分）。

> 本モデルは教育用の簡略化であり、実在の薬・菌・地域の予測ではない。回復人数は仮想的な数値である。ゲーム内の「1年」は新薬の使用開始からの期間で、開発・承認に要する期間とは無関係。

## 1. 2つの時間スケール
| | 短期モデル（患者1人の治療） | 長期モデル（地域の1年間） |
|---|---|---|
| 時間単位 | 時間 [h]、dt = 0.05 h、RK4 | 日 [day]、dt = 0.125 day、確率的 tau-leaping |
| 期間 | 投与 72 h ＋ 投与後 72 h（免疫のみ） | 365 日（12 か月に集計） |
| 状態 | 菌の個数（連続量）S, Sq, R, Rq | 感染者数（整数）Y_S, Y_R |
| 出力 → 入力 | 治療成績 eS, eR と、治療中に耐性が成立する確率 qE | 各月の耐性菌割合 → 100人の患者の感染の種類 |

1人の患者に365日投薬するモデルではない。地域で次々に起こる感染と治療（各回は短期モデル）を1年間追跡する。

## 2. 短期モデル（v1 の式を再利用）
状態 [個]: S（新薬が効く菌・活動状態）, Sq（同・一時的に薬が効きにくい状態）, R（耐性菌・活動状態）, Rq（耐性菌・一時的に薬が効きにくい状態）。

```
N = S+Sq+R+Rq,  crowd = max(0, 1−N/K),  imm = m·Ki/(Ki+N)                      [1/h]
C(t) = Σ_{i: 12i ≤ t, 12i < 72} Cpeak·exp(−ln2/t½ · (t − 12i))                    [MIC 相対, 無次元]
kS = Emax·H(C, EC50),  kR = Emax·H(C, F·EC50),  H(C,E) = C^h/(C^h+E^h)           [1/h]
dS/dt  = gS·crowd·S − kS·S − a·S + b·Sq − imm·S
dSq/dt = a·S − b·Sq
dR/dt  = gR·crowd·R − kR·R − a·R + b·Rq − imm·R,     gR = gS·(1−c)
dRq/dt = a·R − b·Rq
```
次元: 右辺はすべて [個/h]（速度定数 [1/h] × 個数）。各 RK4 ステップ後に max(0,·)（非負性）。

- 治癒判定: 72 h 時点で S+R < 1万個（v1 と同じ）。患者ごとの免疫 m_i と副作用耐性 tol_i は v1 と同じ決定論的配置（正規分位点）。
- 2種類の感染を計算: 新薬が効く菌による感染（S0 = 1億個）と、耐性菌による感染（同数が耐性菌）。

### 2.1 治療中の耐性の成立
区別する4つの量:
| 量 | 記号 | 意味 | 研究レベルとの関係 |
|---|---|---|---|
| 出現頻度 | f | 治療前の集団に耐性菌が混ざっている割合 | `freq[L]` = 10⁻⁹ → 10⁻¹²（耐性の生じにくさ） |
| 突然変異率 | μ | 1回の分裂で耐性菌が生じる確率 [/分裂] | μ = f·c（変異と淘汰のつり合い f = μ/c から導出） |
| 成立確率 | 1/G(t) | 生まれた耐性菌の系統が絶滅せず残る確率 | 薬の濃度・免疫・菌の混み合い・耐性菌の増殖力から決まる |
| 増殖能力 | gR = gS(1−c) | 耐性菌の増殖速度（耐性の増殖コスト c） | `cost[L]` = 0.03 → 0.12 |

1個の耐性菌の系統を、出生率 b(t) = gR·crowd(t)、死亡率 d(t) = kR(t) + imm(t) の非斉次出生死亡過程とみなす。時刻 t₀ に生まれた系統が H = 144 h に生き残る確率は
```
P(t₀) = 1 / G(t₀),   G(t₀) = 1 + ∫_{t₀}^{H} d(s)·exp(−ρ(s)) ds,   ρ(s) = ∫_{t₀}^{s} (b−d) du
離散化（後ろ向き）: G(t) = 1 + d(t)·dt + exp(−(b−d)(t)·dt)·(G(t+dt) − 1),  G(H) = 1
```
期待される生き残り系統数 E = Σ μ·gS·crowd·S·dt / G(t) ＋ S0·f / G(0)（第1項＝治療中に新たに生じる耐性菌、第2項＝治療開始時から存在する少数の耐性菌）。治療中に耐性が成立する確率 pEmerge = 1 − exp(−E)（成立事象をポアソン過程とみなす）。

- この式は閉じた形の解と一致することを確認した（純死亡 b=0: e^{−dT}、純出生 d=0: 1、b>d 定数の長時間極限: 1 − d/b）。`model-ref/model3.py` の検証コード参照。
- 免疫が強い患者では、新薬が効く菌が減ったあと（N が小さい）に imm ≈ m > gR となり、耐性菌の系統は免疫で排除されやすい。耐性が成立するのは主に免疫の弱い患者で、治療開始直後に耐性菌が大きく増えた場合である。
- **「耐性の生じにくさ」は kR（耐性菌への殺菌力）を変えない。** 変えるのは f（およびそれから導かれる μ）と c のみ。
- 殺菌力と持続時間は、濃度が耐性菌の EC50（F·EC50）付近を超える時間を通じて成立確率に影響する（変異株選択ウィンドウの考え方）。

## 3. 長期モデル（地域）
状態 [人]: Y_S（新薬が効く菌による感染者）、Y_R（耐性菌による感染者）、X = N − Y_S − Y_R（感染していない人）。

1ステップ（dt 日）ごとの事象（すべて整数、乱数は mulberry32）:
```
newS   ~ Poisson((β·X·Y_S/N + λ)·dt)          新たな感染（伝播＋外部からの持ち込み）
newR   ~ Poisson(β(1−c)·X·Y_R/N·dt)           耐性菌の伝播（増殖コストで感染力が下がる）
treatS ~ Bin(Y_S, 1−e^{−τdt})                 治療を受ける
emerg  ~ Bin(treatS, qE)                       治療中に耐性が成立 → Y_R へ
curedS ~ Bin(treatS−emerg, eS/(1−qE))          治癒
natS   ~ Bin(Y_S−treatS, 1−e^{−γdt})           自然治癒
treatR ~ Bin(Y_R, 1−e^{−τdt}),  curedR ~ Bin(treatR, eR),  natR ~ Bin(Y_R−treatR, 1−e^{−γdt})
```
eS = 平均[(治癒 ∧ 副作用なし)·(1−pEmerge)]、eR = 平均[耐性菌感染で治癒 ∧ 副作用なし]、qE = 平均[pEmerge]（100人の患者表から）。

- 初期: Y_S = 390（新薬がない状態の流行）、Y_R = 0（耐性菌による感染者はいない。体内の少数の耐性菌は 2.1 の f で扱う）。
- 耐性菌の出現は Poisson/二項乱数で決まり、特定の月に固定されない。早期に絶滅することも、広がることもある。
- 月ごとの集計: その月に含まれる日の Y_S, Y_R の平均と、耐性菌割合 Y_R/(Y_S+Y_R) ∈ [0,1]。グラフは**人数**と**割合**を別の図で示す。
- 100人の患者: 各月 8〜9 人。その月の耐性菌割合の確率で耐性菌感染、そうでなければ新薬が効く菌の感染（その治療中に pEmerge の確率で耐性が成立）として回復を判定する。
- 「耐性菌が広がった」: 12 か月目の耐性菌割合 ≥ 10%。

## 5. 検証（Python。Wolfram は利用できる環境がなく使用していない）
- 生存確率の漸化式: 純死亡・純出生・長時間極限の解析解と一致（誤差 < 0.3%）。
- 短期モデルの時間刻み: dt = 0.1 / 0.05 / 0.025 h で qE = 6.849e-4 / 6.855e-4 / 6.857e-4（設計 2,4,2,4）。治癒判定は同一。
- 地域モデルの時間刻み（設計 2,4,2,4、広がる確率）: dt = 1 日 0.275（200 シード）、0.5 日 0.215、0.25 日 0.160±0.018（400 シード）、0.125 日 0.150±0.018、0.0625 日 0.133±0.017。dt = 1 日は過大評価のため 0.125 日を採用（残る偏りは数ポイント程度）。
- 再現性: 同じシードで完全一致。TS 実装は golden3（6 設計 × 3 シード、患者表と月別推移）で Python と一致。
- 全設計スイープ: `model-ref/sweep3.py`（結果は §6）。

## 7. 仮定と限界
- 感染症・地域・薬はすべて仮想。数値は教育用の仮定・調整値を含む。
- 耐性の獲得は1段階（F = 8 倍）のみ。段階的な耐性の上昇、耐性遺伝子の水平伝達（プラスミド等）の地域間移入、交差耐性、併用療法、治療失敗後の代替薬は扱わない。
- 耐性菌の体内での成立は分岐過程の近似（成立後の系統どうしの相互作用、q 状態を経由する系統の生存は省略）。
- 地域モデルは均一混合で、年齢・病院・抗菌薬使用量の違いを扱わない。
- 100人の患者は各月から均等に選ぶ（実際の受診数の季節変動は扱わない）。
- 「耐性菌が広がった」の基準（12 か月目に 10%）はゲーム上の定義。
