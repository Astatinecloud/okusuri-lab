# あそびかた（おくすり発明ラボ）

1. **はじめる** をおす。
2. **けんきゅうコイン 9まい** をつかって、薬の4つの性能をきめる（1だんあげると1まい）。
   - 💪 ふつうのばい菌への強さ … ふつうのばい菌をへらす力
   - 🔑 新しいしくみ … 薬がききにくいばい菌にもきくようにする工夫
   - ⏰ 薬がはたらく時間 … 長いほどよくきくけど、体への負担もふえる
   - 💚 体へのやさしさ … 薬が体に合わない人をへらす
   - コインがたりない だん は 🔒。ほかの性能を下げるとコインがもどる。
3. **薬を完成させる！** → 薬の名前をきめる（じぶんの名前は入れない）。
4. 体の中のようすを見る（「けっかを見る」でとばせる）。
5. **けっか**：100人中なん人が元気になったか、ランク、はっけんしたこと。
6. **けっかを保存する**：画像をダウンロード（iPhoneは長押し）／QRコードでスマホにもちかえる。
7. **もう一度つくる** で、ちがう組み合わせをためそう！

## ヒント
- 強さだけを上げても、薬がききにくいばい菌はへらないよ。
- 新しいしくみだけでも、ふつうのばい菌がのこることがあるよ。
- はたらく時間が長すぎると、体に合わない人がふえるよ。
- いろいろな性能を組み合わせると、もっと多くの人を助けられるよ。
