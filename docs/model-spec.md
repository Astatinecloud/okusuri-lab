# おくすり発明ラボ 数理モデル仕様書

> 本モデルは科学教育用の簡略化モデルである。数値はすべて**教育用の仮定値またはゲームバランス調整値**であり、実在の薬・菌・臨床試験の値ではない。回復人数は仮想的な数値で、治療成績の予測ではない。

参照実装: `model-ref/model.py`（スカラー版）, `model-ref/sweep.py`（全設計ベクトル版、両者の結果一致を確認済み）。
ゲーム実装: `src/model/`（TypeScript）。パラメータ: `src/config/params.json`（Python と共通）。

## 1. 状態変数（1人の患者の感染部位、単位: 細菌の個数）

| 記号 | 意味 |
|---|---|
| S  | 通常の細菌（感受性株）・活動状態 |
| Sq | 通常の細菌・一時的に薬が効きにくい/薬が届きにくい状態 |
| R  | 薬剤耐性菌（遺伝的耐性株）・活動状態 |
| Rq | 薬剤耐性菌・一時的に薬が効きにくい/薬が届きにくい状態 |

**遺伝的耐性と一時的な効きにくさを区別する。**
- S と R の違いは遺伝的で、観察期間中に入れ替わらない（突然変異・遺伝子伝達はモデル化しない）。
- 活動状態 ⇄ q状態 は可逆な表現型の切替（休眠・持続生残 persistence や、バイオフィルム等の薬が届きにくい場所にいることを抽象化）。**通常菌も耐性菌も同じように q 状態に入れる**。q状態の菌は「永久に薬が効かない菌」ではなく、活動状態に戻れば再び薬の作用を受ける。

## 2. 方程式

時間 t [h]、0 ≤ t ≤ T = 72 h（3日間）。

```
N      = S + Sq + R + Rq
crowd  = max(0, 1 − N/K)                       (ロジスティック増殖の混み合い)
C(t)   = Σ_{i=0}^{⌊t/τ⌋} Cpeak · exp(−k_e (t − iτ)),  k_e = ln2 / t½(作用時間レベル)
H(C,E) = C^h / (C^h + E^h)                      (Hill 型 Emax モデル)
kS(t)  = Emax · H(C, EC50_S)                    通常菌への殺菌速度 [1/h]
kR(t)  = Emax · H(C, EC50_S × F)                耐性菌への殺菌速度 [1/h]
imm    = m · Ki / (Ki + N)                      免疫による1個あたりの排除速度（飽和型）

dS/dt  = gS·crowd·S − kS·S − a·S + b·Sq − imm·S
dSq/dt = a·S − b·Sq − ε·kS·Sq − φ·imm·Sq
dR/dt  = gR·crowd·R − kR·R − a·R + b·Rq − imm·R
dRq/dt = a·R − b·Rq − ε·kR·Rq − φ·imm·Rq
```

- EC50_S は「ふつうのばい菌への強さ」レベルで決まる（薬そのものの力。**投与量 Cpeak は全設計で同じ**＝「薬をたくさん飲む」ことはモデルに存在しない）。
- F（耐性による EC50 の倍率）は「新しいしくみ」レベルだけで決まる。F = 64, 8, 3, 1.6, 1。
- q状態では ε = 0（薬は効かない）、φ = 0（免疫も届きにくい）。q状態の菌は b の速さで活動状態に戻り、戻ったところで薬・免疫の作用を受ける。

### 2.1 「新しいしくみ」の数学的な意味
耐性菌は、このゲームで想定する耐性機構（分解・排出・標的変化などを1つに抽象化）により、同じ効果を得るのに通常菌の F 倍の濃度を必要とする。
新しいしくみの研究は F を 64 → 1 に下げる（＝耐性機構を回避・別の作用機序を利用）。

レベル1では EC50_R = EC50_S × 64。強さを最大（EC50_S = 0.75）にしても EC50_R = 48 で、到達濃度（最大でも約 8）は EC50_R に遠く届かず、kR は耐性菌の増殖速度より小さいまま → **強さだけ上げても耐性菌は減らない**（テストA, E）。
新しいしくみが十分なとき（F ≤ 3）には、薬の強さが耐性菌にも「とどく」ようになる。

これは本ゲームで想定する「高度耐性」の組み合わせに限ったルールであり、一般の医学的法則ではない（現実には耐性の程度により濃度で効果が変わる場合もある）。

### 2.2 耐性菌が残る理由
1. 治療開始時、各集団の 0.1%（tolFrac0）が q 状態にある（仮定）。
2. q 状態の菌には薬も免疫も効かず、b = 0.02 /h の速さでゆっくり活動状態に戻る。戻った菌は薬で倒される。
3. 72時間の観察期間では q 状態の菌は約 exp(−0.02·72) ≈ 24% までしか減らない。
→ 残存は有限の観察時間・q状態からの復帰速度・初期条件から**モデルの中で生じる**。最低残存数を後から付け足す処理はしない。
観察期間を延ばしたり、q 状態からの復帰を早めたりすれば、残存はさらに減る（＝「現実に絶対根絶できない」というモデルではない）。

### 2.3 連続量と個体数（表示の整合性）
本モデルは個数を連続量で近似する決定論的モデルで、個数が十分大きいときに妥当である。
グラフに表示する代表患者では、全 435 通りの設計で耐性菌の終了時個数は **最小約 35 個、通常菌は最小約 3.5 万個**であり、1個未満の値を「1匹」と丸めて表示する必要は生じない（`sweep.py` で確認）。
画面上の丸め表示は「約◯個」「◯分の1」とし、0 と表示しない理由がモデル値そのもの（≥ 35）にある。

## 3. 100人の仮想患者

患者 i（i = 0..99）は次の3つが異なる（正規分位点 z_i = Φ⁻¹((i+0.5)/100) を用いた決定論的な配置。乱数は使わず、同じ設計なら必ず同じ結果）。

| 量 | 式 | 意味 |
|---|---|---|
| 免疫の強さ m_i | 1.0 · exp(0.3 · z_i) | 体の守る力 |
| 耐性菌の初期数 log10 R0_i | 3.4 + 1.5 · z_{(37i mod 100)} | 患者ごとに耐性菌のまじり方がちがう |
| 副作用への耐えやすさ tol_i | 1.0 · exp(0.35 · z_{(61i+17 mod 100)}) | 体質の個人差 |

全患者で S0 = 1e8。

**回復の判定**（患者ごと）
1. その患者のパラメータで 72 時間シミュレーション。
2. 治った（感染がおさまった）: 終了時の活動状態の菌 S + R < 1e4。
   - 菌がゼロでなくても、少数なら免疫が片づけられる（飽和型免疫モデルでは低密度の菌は免疫で排除される）。
   - q状態の菌は判定に直接は入れない（症状の原因になる増殖中の菌が抑えられたかを見る）。ただし q 状態が多いと活動状態への復帰で S+R が下がりきらず判定に影響する。
3. 副作用で元気になれなかった: 副作用の強さ se ≥ tol_i。
   `se = 0.85 · (1 + sePot + seMech + seDur) · seGentle`
4. 元気になった人数 = 2 を満たし 3 に当たらない人数（0〜100の整数）。

**代表患者**（グラフ・アニメ・「へった割合」に使用）: m = 1.0、log10 R0 = 5（耐性菌がはじめ 10万個 = 1000個に1個）。

## 6. モデルの仮定と限界
- 1つの感染部位、決定論的 ODE。個数が小さい領域（< 数十個）の確率的ゆらぎは扱わない。
- 耐性の新規獲得（突然変異・遺伝子伝達）、薬による q 状態誘導、組織移行、再発は扱わない。
- 副作用は「体質の個人差」との単純比較であり、実際の毒性評価ではない。
- 予算・コストはゲームのルールで、実際の研究開発費とは無関係。
- Wolfram は本開発環境で利用不可のため**使用していない**。検証は Python（numpy）で実施。
