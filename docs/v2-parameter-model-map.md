# v2 パラメータと計算式の対応表・仮定と制約・モデル検証

対象: v2（高校生〜文系大学生向け改修）。**モデル式・params.json の値は v1 から変更していない。** 変わるのは表示・説明・分析機能のみ。

## 1. パラメータ → 計算式の対応

| 画面上の名称（v2） | 内部キー | 影響する式 | レベル1→5 の値 | 主に変わる結果 |
|---|---|---|---|---|
| 薬剤感受性菌への効果 | `pot` | 感受性菌の EC50（EC50_S）。耐性菌の EC50 は EC50_S × F なので、F が小さいときに限り耐性菌にも効く。副作用指数にも小さく加算（sePot） | EC50_S = 3.2, 2.2, 1.5, 1.05, 0.75 / sePot = 0, .05, .10, .15, .20 | 感受性菌の最終数、回復数（治療成功）、副作用中断数（わずか） |
| 薬剤耐性菌への作用（新しい作用機序） | `mech` | 耐性による EC50 倍率 F。副作用指数に加算（seMech） | F = 64, 8, 3, 1.6, 1 / seMech = 0, .03, .06, .10, .14 | 耐性菌の最終数、回復数、副作用中断数（わずか） |
| 作用持続時間 | `dur` | 薬物濃度の半減期 t½（C(t) の減衰速度）。副作用指数に加算（seDur） | t½ = 3, 4.5, 6.5, 9, 12 h / seDur = 0, .08, .16, .28, .42 | 薬が増殖を上回る時間、両菌の最終数、副作用中断数（大きい） |
| 安全性（副作用の少なさ） | `gentle` | 副作用指数に掛かる係数（seGentle） | 1.0, .80, .62, .47, .35 | 副作用中断数のみ（細菌数には影響しない） |

- 研究開発費: レベル L にするには (L−1) × 10 pt。上限 90 pt（v1 の「コイン9枚」と同じルールを表示単位だけ変更）。**ゲーム上の単位であり実際の開発費ではない。**
- 投与量 Cpeak = 4、投与間隔 12 h は全設計で共通。**どの性能も「投与量を増やす」操作ではない。**
- 副作用指数 se = 0.85 × (1 + sePot + seMech + seDur) × seGentle。

## 2. 細菌数 → 回復人数の換算（仮定）
1. 100人の仮想患者は「免疫の強さ m」「耐性菌の初期数 R0」「副作用への耐性 tol」が異なる（正規分位点で決定論的に配置。**乱数は使っていない**ので比較に偶然の変動は入らない）。
2. 患者ごとに 72 時間の ODE を解き、終了時の活動状態の菌（S + R）が 1万個未満なら「感染が制御された」とみなす（飽和型免疫モデルでは低密度の菌は免疫で排除されるという仮定）。
3. se ≥ tol の患者は「副作用で治療継続が困難」として回復に数えない。
4. 回復 = 2 を満たし 3 に当たらない人数。

## 3. 耐性菌が残る理由（モデル上の説明）
- 各集団の 0.1% が初期に「一時的に薬が効きにくい状態（q 状態：休眠・持続生残や、薬の届きにくい部位を抽象化）」にある。q 状態の菌には薬も免疫も作用しない。
- q 状態から活動状態への復帰は b = 0.02 /h と遅く、72 時間では約 24% までしか減らない。復帰した菌は薬で倒される。
- **残存はこの有限の観察期間と復帰速度から生じるモデルの予測であり、最低残存数を後付けする「ゲーム上の制約」は存在しない。** 観察期間を延ばせば残存はさらに減る。
- q 状態は遺伝的耐性とは別の現象で、感受性菌にも同じように存在する（感受性菌も約 3〜4万個が残る）。
- 耐性菌の数が減っても、残った菌は耐性遺伝子を持ったままである（耐性そのものが消えたわけではない）。

## 4. 科学的根拠と仮定の区別
| 区分 | 内容 |
|---|---|
| 文献で支持される**考え方**（数値は採用していない） | 遺伝的耐性と一時的な効きにくさの区別（Brauner et al. 2016）／可逆な表現型切替（Balaban et al. 2004）／Hill 型薬力学関数（Regoes et al. 2004）／抗菌薬と免疫の協働（Ankomah & Levin 2014） |
| 教育用モデルの仮定 | 単一感染部位、決定論的 ODE、ロジスティック共有収容力、飽和型免疫、q 状態の割合と切替速度、投与スケジュール、回復判定の閾値 |
| ゲームバランスの調整値 | EC50_S・F・t½ の各レベル値、免疫と R0 の分布、副作用係数、研究開発費と予算 |
| モデルに含めていないもの | 耐性の新規獲得（突然変異・遺伝子伝達）、薬による q 状態誘導、組織移行、治療終了後の再発、確率的ゆらぎ |

## 5. モデル検証の結果（v2 改修時、全 435 設計・1段階変更 320 組ずつ）

| パラメータを1段階上げたとき | 回復数↑ | 回復数↓ | 不変 | 耐性菌最終数が増えた組 | 感受性菌最終数が増えた組 |
|---|---|---|---|---|---|
| 感受性菌への効果 | 217 | 76（最大 −5人） | 27 | 0 | 0 |
| 耐性菌への作用 | 195 | 63（最大 −4人） | 62 | 0 | **137** |
| 作用持続時間 | 144 | 106（最大 −11人） | 70 | 0 | 0 |
| 安全性 | 215 | 0 | 105 | 0 | 0 |

- 回復数が下がる組は、いずれも副作用指数の増加による（説明と一致）。安全性は細菌数を変えない（説明と一致）。
- どの性能を上げても耐性菌の最終数は増えない。
- **要注意の挙動**: 「耐性菌への作用」を上げると感受性菌の最終数が増える組が 137 ある。最大は (効果1, 作用4→5, 時間1) で約 490万 → 約 8.4億個（約170倍）。原因は共有収容力 K のもとでの**競合の解放**: 感受性菌を十分に抑えられない弱い薬で耐性菌だけを減らすと、空いた環境を感受性菌が埋める。生態学的には説明可能な挙動なので**モデルは変更しない**。代わりに、この現象が起きたときは性能分析で「耐性菌が減ったことで、感受性菌が増殖できる余地が生まれた（競合の解放）。感受性菌への効果も必要」と明示する。
  - 修正案（今回は採用せず）: 感受性菌と耐性菌が別々の収容力を持つ（異なる部位にいる）と仮定すればこの挙動は消えるが、混合感染で両者が資源を奪い合うという現在の仮定の方が自然と判断した。
